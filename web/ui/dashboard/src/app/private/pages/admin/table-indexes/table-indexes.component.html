Table indexes

An index build that is interrupted leaves the index behind marked invalid, and the planner ignores it from then on, so the table performs as if the index had never been created without any query failing to say so. Upgrades drop what they find, which is instant, and record the definition so the rebuild can happen here on your schedule.
