How event search works

Text matches event ID, event type, source name, and idempotency key.

JSON object filters the payload with exact JSON containment. Every key and value you include must match the stored body at the same path.

Examples: {"status": "paid"} or nested {"data": {"status": "paid"}}. Relaxed input such as {status: "paid"} or data: {status: "paid"} is also accepted. Bare status: "paid" is text search, not payload.

Mix text and JSON to require both, for example invoice.paid {"status": "paid"}.

Open an event and mirror the field paths shown in the payload panel. A nested field is not the same as a top-level field with the same name.
